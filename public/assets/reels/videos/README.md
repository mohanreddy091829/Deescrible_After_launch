Drop reel files here (MP4, H.264, 9:16, ideally ≤ 8 MB each) and set `video` / `poster`
on the matching entry in `data/reels.ts`, e.g.

  video: "/assets/reels/videos/varanasi-diaries.mp4",
  poster: "/assets/reels/videos/varanasi-diaries.jpg",

Entries without a video render as a designed poster card and auto-advance.
